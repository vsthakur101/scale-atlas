nothing is lost. Per `docs/topic-triage.md`, most of these are lists, roadmaps, vendor/tool tours, book lists,
interview playbooks or near-duplicates of lessons already written, and are not planned. To write one: author
`src/course/lessons/<slug>.ts`, then add an entry to the matching index file (titles are references only).
